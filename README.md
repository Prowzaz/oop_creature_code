# How to Run and Test
From the project folder, run:

# bash
python creature_simulation.py


The `if __name__ == "__main__":` block runs the tests for `Creature`

Tests 1–7, including `FireCreature`, `FlyingCreature`, and
`SwimmingCreature`. Each test prints the expected value next to the actual value so you can compare them.
